# MetOrigin Splat 当前设计规范

本文件描述当前桌面界面及其维护约束，更新基准为 2026-11-01。平台、引擎路线、候选构建及未关闭验收统一见[当前状态](status.md)；旧方案和逐次实测保留在[设计档案](archive/design/)。规范中的尺寸是源码布局约束，不代表所有平台、DPI、辅助技术或实际缩放场景已经验收。

## 1. 来源与职责

界面采用 Jan 固定提交 `b8d58255baf6d9e870025d3f0c60a5b80a63143b` 的主题与视觉源码，融合原有 shadcn/ui 与 Radix 基础组件。本产品包含 Menlo Research 开发的 Jan 软件；Jan 的 Apache-2.0、Menlo Research 归属和本地修改声明与 shadcn/ui 的 MIT 声明分别保留。

- 主题唯一来源：[theme.json](../integrations/jan/theme.json)。宿主 tokens 由生成脚本输出，编辑器构建消费同源数据。
- 组件来源与本地改动：[ui-sources.json](../apps/desktop/ui-sources.json)、[组件维护说明](../apps/desktop/src/components/ui/README.md)。
- Jan 原文与来源身份：[Jan 集成](../integrations/jan/README.md)。Meshroom 仅提供照片网格的视觉组织参考，没有复制 QML 或引入其依赖。
- 现有 AppContext、前端 desktop service、Tauri/Rust、工程 schema、流水线和保存/退出保护继续拥有业务状态；视觉适配不引入 Jan 的路由、Store、账号、ServiceHub、遥测或模型业务。

更新来源时比较固定提交的差异，选择已提取的文件，同步适配和来源清单，再检查行为与视觉。固定原文、许可证及 NOTICE 不因主题整理而改写，也不将不同来源统一重标许可。

## 2. 桌面外壳与导航

共用首行高 48px。展开时，首行左侧导航区与正文全高侧栏同宽；内容页头和主内容紧接侧栏，使用齐边桌面分区。页面没有外围网页式留白或包住主区的大圆角卡片，操作系统窗口圆角保留。

| 区域 | 当前规则 |
| --- | --- |
| 侧栏 | 默认 240px，可在 224–320px 调整；支持指针拖动与键盘调整 |
| 侧栏入口 | 只保留“项目中心”和底部“设置与引擎”；项目列表、新建和打开集中在项目中心 |
| 隐藏侧栏 | 正文占位为 0，隐藏内容退出焦点序列；展开恢复先前宽度，不保留 64px rail |
| 首行开关 | 32px 圆形点击区、18px 图标；不显示后退/前进按钮或占位 |
| macOS 首行 | 原生交通灯左侧安全区 84px，开关置于安全区之后 |
| Windows 首行 | 展开时保留 MetOrigin 图标及品牌；不添加 macOS 交通灯留白 |
| 窄窗导航 | 项目抽屉提供项目中心与设置入口，并保留关闭、焦点恢复及安全导航 |

窗口首行、场景宿主及编辑器 header portal 在侧栏开合、拖动与设置变化时保持节点稳定。窄窗、分栏变化不通过重新挂载 renderer 或 iframe 来实现。拖动侧栏期间暂时关闭 iframe 指针事件，结束后恢复。

macOS 使用 AppKit 标准交通灯，实际按钮圆心按首行 24pt 垂直对齐；保留系统横向间距、尺寸与动作，全屏时交给系统。平台窗口初始大小以 [Tauri 基础配置](../apps/desktop/src-tauri/tauri.conf.json)和[Windows 覆盖配置](../apps/desktop/src-tauri/tauri.windows.conf.json)为准，不在设计文档中维护第二份跨平台统一窗口尺寸。

## 3. 主题、字体与尺寸

`light | dark | system` 由既有 `useTheme` 管理，`html[data-theme]` 是生效源。宿主入口为 [app.css](../apps/desktop/src/styles/app.css)，生成值在 [tokens.css](../apps/desktop/src/styles/tokens.css)，领域布局在 [workspace.css](../apps/desktop/src/styles/workspace.css)。修改主题来源后生成 tokens，不手工维护第二套色表。

| 用途 | Light | Dark |
| --- | --- | --- |
| 页面背景 | `#ffffff` | `#121212` |
| 主文字 | `#0a0a0a` | `#fafafa` |
| 面板/浮层 | `#ffffff` | `#171717` |
| 主操作 | `#be4c30`，白色文字 | `#f17455`，`#171717` 文字 |
| 主操作 hover | `#a93d25` | `#fb8d72` |
| 侧栏 | `#f1f1f1` | `#171717` |
| 辅助文字 | `#666666` | `#a1a1a1` |
| 分隔线 | `#e5e5e5` | `#303030` |
| 输入边界 | `#858585` | `#767676` |

成功、警告、危险、焦点和未知状态使用已有语义 token；状态还必须有文字或必要图标，颜色不单独承载含义。三维视口保留独立暗色表面，主题只调整 UI，不改变模型材质、选区/轴语义或输出图像颜色。

- 基础字号为 16px，常用正文和控件为 14px；辅助信息通常 12px。
- 使用本地 Inter Variable 与系统中文字体回退；路径、日志和技术值可使用 JetBrains Mono。没有复制 Jan 字标或 StudioFeixen 字体。
- `--radius` 为 `0.625rem`；基础输入保留 Jan 圆角，主要按钮使用 pill。按钮高度 xs/sm/default/lg 分别为 24/32/36/40px，对应图标按钮为相同尺寸。
- 结果数值静态按 locale 格式化，可使用 tabular-nums；当前不加载 Magic UI NumberTicker 或 Motion 数字动效。
- 长中文、英文按钮和路径允许增长、换行或有上下文的省略；未知测量显示未知，不伪装为 0。

## 4. 组件、焦点与反馈契约

业务组合复用 `components/ui` 与既有 shell/settings/workspace/feedback 组件，不为视觉改名另建业务状态机。

| 组件或行为 | 维护约束 |
| --- | --- |
| Button | 默认 `type="button"`；领域语义使用已有 variant；disabled、pending 来自实际状态 |
| Input / NativeSelect / Label | 保留原生输入、选择及 IME 行为；label 与控件关联 |
| Checkbox / Switch | 使用 Radix 状态；确认事项与即时布尔偏好分开表达 |
| Progress | 已知值使用实际 value，未知为 null；不得用装饰计时生成百分比 |
| Dialog / ModalSurface | Radix 管理焦点限制；应用管理 busy、初始焦点、关闭限制及返回目标 |
| Menu / Tooltip | 使用当前模态的 Portal scope，避免内容离开可访问子树；Tooltip 不能替代可访问名称 |
| DesktopMenu / ContextMenu | 保留键盘、Esc返焦和Tab退出约定；右键释放只打开菜单，不执行动作 |
| Resizable | 面板调整保持视口节点和资源所有权稳定 |
| 错误与回执 | 错误保留可操作文本和重试上下文；诊断沿用脱敏边界，原始引擎输出不作为普通用户消息 |

同一弹层只有一个焦点管理器。busy 状态禁用不安全的 Escape/外部关闭，并保留可用焦点；关闭后返回 opener，失效时使用调用点 fallback。全局快捷键忽略输入与活动弹层，不能绕过向导取消或编辑器离开保护。

## 5. 页面组合

### 项目中心

项目数量、名称/完整路径搜索、打开和新建集中在可换行工具栏。主区使用自适应方形缩略图；网格列基准180px，卡片上限220px，图片还受卡片内边距和窄容器约束，图下只显示项目名称；不提供状态筛选菜单、常驻训练状态行或路径异常块。训练状态、阶段、路径健康、完整路径和更新时间仍保留在 title、无障碍描述及安全判断中。

搜索不因状态或路径健康隐藏项目，全库不采用导航组件默认的50项截断。成功打开项目才前移最近顺序，后台状态更新保序。更多菜单与右键菜单共享项目管理和安全导航；重试检查、重新定位等恢复操作继续可达，实际重新定位失败或 UUID 不匹配保留可操作反馈。

缩略图代表项目内真实输入素材：优先 frames 首张图片，再回退 source 中已复制的照片。只读命令校验项目身份、路径与普通文件，限制扫描、文件和像素大小；不调用引擎、抽视频帧或写磁盘缓存。前端靠近可见区加载，并发2、48项内存LRU，迟到响应按项目/路径/版本隔离。缺图、加载与失败使用局部占位，不生成替代照片或暗示重建质量。

### 三步创建向导

保留“选择素材 → 预检与参数 → 确认创建”。步骤标记为24px，正文最大960px；主体可滚动，底部提交和安全退出入口清楚。

素材入口为紧凑选择区；拍摄建议默认折叠，最多6张预览按2/3/6列重排。参数页先呈现预设，选中项使用主色填充、勾选与 `aria-pressed`；参数详情和正常环境详情默认折叠。阻断时环境详情自动展开，warnings、blockers及修复入口位于折叠区外。后端执行限制按实际返回值展示，不能把示例值写成固定产品参数。

确认页使用标签行表单与轻量摘要。切换参数使旧预检失效；目录重检、单飞创建、复制取消、失败/部分成功与退出确认仍由原控制器处理。

### 重建工作台

共用首行的 compact 运行栏保留项目名、适用任务控制、编辑和操作菜单，不显示旧状态/进度入口、完成标签或独立文件按钮。文件定位留在菜单，现行界面不提供“从最近项目移除”菜单项；底层保留的服务不能作为可见入口说明。非 compact 完整运行栏仍可显示整体进度、状态、阶段与更新时间。

四阶段使用数字或完成勾、阶段名、细连接线和展开箭头。完成态不逐格重复“已完成 · 100%”；完整状态与进度仍在 title/无障碍名称中。子阶段可展开、键盘选择预览；失败重试和质量阻断修复由 Inspector 的原恢复入口处理。

场景与 Inspector 为稳定的兄弟面板，窄窗 Inspector 使用模态。主工作台隐藏底层预览工具栏，不展示实时频率下拉、重置/整体/网格按钮或独立“跟随当前阶段”按钮；选择运行阶段会自动恢复跟随。完成态仅一个“重建完成”标题与结果说明，运行/暂停/取消/失败态保留真实进度和恢复反馈。质量区区分“相机重建检查”、照片/视频帧注册率、稀疏点数与高斯点数；主要匹配组覆盖率不能冒充整体模型质量。恢复点表示 PLY 几何恢复，不表示完整优化器状态恢复。

恢复点成功但为空时不留占位；loading、refreshing、error、stale、partial与重试继续保留。模型更新失败尽可能保留最后有效模型和用户相机。当前浏览项目和全局运行项目分别表达，切页不暗示停止任务。

### 设置

设置是稳定桌面壳上的模态，主页面继续挂载。内部标题高60px；桌面分类区232px，正文独立滚动，窄窗分类重排。分类为常规、引擎、性能与存储、外观、诊断。

显式保存的数值设置保留本地草稿，后端成功回执后才采用；失败保留输入供重试。主题、语言等即时偏好继续使用原保存机制，不把输入中间态写入后端。

## 6. SuperSplat 编辑器边界

固定官方 SuperSplat 3.7.0（`b89029dd20911fd18905b61de2701094ac390a73`）、splat-transform 3.10.2及对应 [WebP派生链](../integrations/supersplat/webp-overlay-3.10.2/README.md)。旧3.4.2载荷与验收是独立历史身份，不能互相替代。

iframe地址和节点保持稳定；主题、语言、设置或侧栏变化不触发模型重新载入。父窗口的 source/origin/channel鉴权、load/dirty/saved/save-failed、单飞、保存会话身份及原子替换继续由现有桥接与后端负责。export使用 `{}` 保留真实SH0–3，不强行补齐为SH3。

主题协议只接收 `light | dark` 与 `jan-v1`，不接收任意CSS、HTML、URL或脚本。宿主拥有语言；嵌入Preferences隐藏重复语言控件，Reset保留宿主语言。主题失败可非阻断重试，不冒充模型失败；同步不重置dirty或相机。

嵌入菜单隐藏menu-home及分隔线，保留宿主标题、右下版本、About与NOTICE。首次偏好迁移仅将camera.showInfo和view.perfOverlay设为false，成功写入后记录marker；其他偏好和之后手动选择保持，损坏/未知存储不清空。展开菜单与场景面板共享24px左边距、320px内容宽度和1px边框，菜单文字水平内边距12px；折叠和standalone保持对应上游行为。

UI主题适配涵盖PCUI、面板、菜单、弹窗及必要Canvas UI绘制，不改变模型材质、轴/选区、颜色算法或序列化。所有派生资源由准备脚本生成，输入进入准备签名和资产清单，不人工编辑public/dist产物。详细区域覆盖与构建依赖见 [ui-theme维护说明](../integrations/supersplat/ui-theme/README.md)。

## 7. 无障碍、本地化与验证

图标按钮必须有可访问名称，字段错误有文本及关联，状态同时表达文字与必要图标。StatusAnnouncer避免资源轮询和连续数字反复打断读屏。中英文字、数值、日期使用现有i18n/locale，可见label和accessible name一致；保留IME输入行为。

普通文字目标对比度4.5:1，必要控件边界和焦点目标3:1。CSS遵循 `prefers-reduced-motion`，不添加持续装饰或真实进度之外的动画。透明叠加、平台绘制、读屏、forced-colors和真实200%缩放仍需按目标平台验证，不能由token测试推断整体合规。

维护界面时检查相关交互/生命周期、来源证据与构建，并按受影响范围检查真实页面和原生行为。样例模式、截图、构建耗时和单元测试分别记录用途；不得据此宣称真实训练、GPU预算、模型保存或完整发布通过。当前平台组合与待验项只在[当前状态](status.md)维护；具体历史结果、构建身份和原始路径保留在[迁移档案](archive/design/frontend-migration-plan.zh-CN.md)及[设计QA档案](archive/design/design-qa.md)。
